# Documentação da API — Loja Gamer

## 1. Objetivo

Integrar uma API externa à página de produtos
da Loja Gamer para consultar e apresentar
informações de produtos.

## 2. API utilizada

Nome: DummyJSON Products API

Endereço:
https://dummyjson.com/products

Tecnologia de comunicação: HTTP

Formato de resposta: JSON

## 3. Funcionalidades

- Consultar produtos na API.
- Exibir nome dos produtos.
- Exibir imagens.
- Exibir preços.
- Exibir descrições.
- Pesquisar produtos.
- Apresentar mensagens de erro quando
  a consulta não funcionar.

## 4. Funcionamento

1. O usuário acessa a página de produtos.
2. O JavaScript realiza uma requisição à API.
3. A API retorna os produtos em formato JSON.
4. O JavaScript interpreta os dados.
5. Os produtos são apresentados na página.

## 5. Tratamento de erros

- Exibir mensagem durante o carregamento.
- Informar quando ocorrer erro na consulta.
- Informar quando nenhum produto for encontrado.

## 6. Tecnologias

- HTML
- CSS
- JavaScript
- Fetch API
- JSON

## 7. Observações

A API será utilizada para fins acadêmicos.
Os produtos retornados serão apresentados
como demonstração de integração com serviços externos.

Os dados da API não representam necessariamente
o estoque real da Loja Gamer.
