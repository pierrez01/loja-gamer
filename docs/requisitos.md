# Requisitos do Sistema — Loja Gamer

## 1. Introdução

O sistema consiste em uma loja virtual de produtos
gamers, permitindo que usuários visualizem e consultem
produtos disponíveis.

## 2. Requisitos Funcionais

RF01 - O sistema deve exibir os produtos disponíveis.

RF02 - O sistema deve apresentar nome, imagem,
descrição e preço dos produtos.

RF03 - O sistema deve permitir pesquisar produtos.

RF04 - O sistema deve permitir filtrar produtos
por categoria.

RF05 - O sistema deve permitir adicionar produtos
ao carrinho.

RF06 - O sistema deve permitir visualizar o carrinho.

RF07 - O sistema deve apresentar informações
de contato da loja.

## 3. Requisitos Não Funcionais

RNF01 - O sistema deve possuir interface intuitiva.

RNF02 - O site deve funcionar em computadores
e dispositivos móveis.

RNF03 - O sistema deve apresentar carregamento
adequado das páginas.

RNF04 - O código deve ser organizado e documentado.

## 4. Restrições

O projeto será desenvolvido utilizando tecnologias
web e controle de versão com Git e GitHub.
