# Funcionalidades da Loja Gamer

## Página inicial
Apresentação da loja e dos produtos em destaque.

## Catálogo de produtos
Exibição dos produtos disponíveis para venda.

## Pesquisa
Busca de produtos pelo nome.

## Categorias
Organização dos produtos por categorias.

## Carrinho
Adição, remoção e visualização dos produtos
selecionados.

## Contato
Informações para contato com a loja.


## Consulta de produtos por API

A página de produtos deverá consultar uma API externa
utilizando JavaScript e Fetch API.

Os dados recebidos deverão ser apresentados
em cards contendo:

- Imagem do produto.
- Nome.
- Descrição.
- Preço.
- Botão adicionar ao carrinho.

O sistema deverá tratar erros de conexão
e ausência de resultados.
