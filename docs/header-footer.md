# Documentação — Header e Footer

## 1. Header (Cabeçalho)

O Header será o componente superior do site,
responsável pela navegação principal.

### Elementos:
- Logotipo da Loja Gamer.
- Menu de navegação.
- Link para página inicial.
- Link para produtos.
- Ícone do carrinho.
- Indicador da quantidade de produtos no carrinho.

### Comportamento:
- O menu deverá permitir navegar entre as páginas.
- O carrinho deverá direcionar o usuário
  para a página do carrinho.
- O Header deverá ser responsivo.

## 2. Footer (Rodapé)

O Footer será o componente inferior do site,
apresentando informações institucionais.

### Elementos:
- Nome da Loja Gamer.
- Descrição da loja.
- Links de navegação.
- Informações de contato.
- Direitos reservados.

### Comportamento:
- Os links deverão direcionar para suas respectivas
  páginas ou seções.
- O Footer deverá ser responsivo.

## 3. Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 4. Responsividade

O Header e o Footer deverão funcionar
adequadamente em computadores, tablets
e dispositivos móveis.
