# Loja Gamer 🎮

## Sobre o projeto

A Loja Gamer é um projeto acadêmico de desenvolvimento
web que tem como objetivo criar uma loja virtual
especializada na venda de produtos gamers.

## Objetivo

Desenvolver uma plataforma onde os usuários possam
visualizar produtos, consultar preços e conhecer
os equipamentos disponíveis.

## Público-alvo

Pessoas interessadas em tecnologia, jogos eletrônicos
e equipamentos para computadores.

## Produtos oferecidos

- Teclados gamers
- Mouses
- Headsets
- Monitores
- Placas de vídeo
- Computadores
- Acessórios gamers

## Tecnologias

- HTML
- CSS
- JavaScript
- Git
- GitHub
